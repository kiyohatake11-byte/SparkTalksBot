# SparkTalks Bot

Anonymous chat-matching Telegram bot with VIP features.

## Setup

1. `pip install -r requirements.txt`
2. Copy `.env.example` to `.env` and fill values
3. `python bot.py`

## Features

- Anonymous matching queue
- VIP subscription (Telegram Stars)
- Media control (accept/decline)
- Report / Block
- Admin panel
- Reaction sync
